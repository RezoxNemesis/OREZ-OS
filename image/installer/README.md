# OREZ installation payload — NOT a certified installer

This folder defines a **whitelisted additional SquashFS** containing only install-safe OREZ user interface files, generated by `build/build-install-payload.sh`. Its purpose is to resolve the demonstrated gap where stock Calamares installs only the Kubuntu base filesystem.

`orez-unpackfs-candidate.conf` is an **inactive candidate** for a future tested Calamares profile. It documents two sequential unpackfs entries: first the original base, with the reported live-only AppArmor override excluded; then `orez-install.squashfs` on top. Calamares documents ordered multiple source support: https://github.com/calamares/calamares/blob/calamares/src/modules/unpackfs/unpackfs.conf .

The profile has **not** been applied, and installation remains disabled by the live-only `/usr/bin/calamares` warning. This is not a full solution: LUKS2, Btrfs, UEFI/GRUB, driver compatibility, package ownership, backup/rollback, effective installed AppArmor, and non-target disk preservation all need disposable-VM tests. The payload is not a signed package or update channel. It does NOT add privileged helpers, background services or hidden switches.
