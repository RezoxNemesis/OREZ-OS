These include build/report screenshots and actual offline UEFI guest captures. They do not prove a finished installer, usable desktop in every VM, target hardware, game performance or comprehensive security. Read the per-run vm_diagnostic and interpretation fields. Earlier exposed passwords belong only to destroyed offline dummy guests, never the owner.
