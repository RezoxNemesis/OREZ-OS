# OREZ OS — 340 original PNG screenshots

This branch is a screenshot download, not OS source, an installer or a PC-ready release.

Download this branch as ZIP and extract it. All 340 original PNG files are in
`images/`; open `index.html` for the gallery. `manifest.json` preserves 551 capture
references and 25 test-attempt records, including failures. PNG bytes are unchanged
from the original local evidence bundle, and every uploaded Git blob hash was checked.

Some images capture native applications in a software-rendered Linux container,
some show the separate browser design preview, and some capture test logs. They
do not establish a booted ISO, hardware compatibility, Android gameplay or safe
installation. See the development branch's DAILY_USE_QA.md and AI_HANDOFF.md.

The original local evidence ZIP also includes raw logs; this GitHub source ZIP
contains images, gallery and manifest only. Its ZIP hash and archive size therefore
differ, while all 340 image hashes remain identical.

Published at the owner's explicit request for a direct GitHub screenshot download.
