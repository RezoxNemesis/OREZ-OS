# OREZ OS visual identity

Approved minimal Japanese sumi-e ink painting: textured warm-white handmade paper, ancient black ink tree, black-clad person resting near trunk. No busy neon. Source vector `overlay/usr/share/backgrounds/orez/orez-ink.svg`.

Paper base `#F6F4EF`, primary text `#161616`, secondary `#595959`. Optional frosted panels must retain contrast, keyboard focus, scaling and reduced-motion settings. Professional KDE multitasking, animations and usability are the foundation. The optional user-level wallpaper setup is reversible with `orezctl appearance disable` and KDE Settings. Full QML/Kirigami visual shell and accessibility certification are not yet complete.
