# Three proposed OREZ differentiators

These are proposals, not implemented claims or reasons to delay a reliable base.

1. **Change timeline and recovery:** correlate owner-approved package, settings
   and service changes with diagnostics. Preview impact and offer tested reversal
   where possible; distinguish snapshots from independent backups and never
   silently roll back newer user files. Build on the real recovery milestone.
2. **Resource-aware workspaces:** explicit Development, Gaming and Creative
   profiles coordinate optional Android/AI/indexing jobs and explain pressure.
   Respect owner budgets, preserve foreground work, show every change and allow
   restore. Require frame-time, memory and energy evidence before claiming gains.
3. **Local device dashboard:** show phone connectivity, hotspot status, mirroring,
   resumable transfers where the provider supports them, and per-device grants.
   One visible disconnect/revoke action; no cloud dependency or remote admin.

Acceptance includes full operation with these features disabled. Reuse mature
OS services and versioned, reversible settings. No feature guarantees superiority
to other operating systems without comparable workloads and evidence.
