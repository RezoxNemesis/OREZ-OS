OREZ OS

Welcome to the first real Linux live-boot engineering candidate. This build adds OREZ desktop components to Kubuntu 26.04.1. You can use ordinary KDE Plasma windows, apps, files and the terminal.

Live-test candidate only. Installation, encryption, NVIDIA and Secure Boot support have not been verified. Do not run the install option or modify your SSD from this build. Test from a separate USB drive.

OREZ Store

Open OREZ Store from the launcher, or run orezctl store. Browse native Linux and actual Android app entries with visible privacy and compatibility details. Android apps are not replaced by websites; the consumer runtime is still pending. The store is free and makes no automatic purchases or administrator grants.

Explore safely

  • Open System Settings to change wallpapers, accessibility, Wi-Fi, software settings, and permissions.
  • Open Dolphin to browse files and USB devices. Avoid formatting drives.
  • Use Konsole for full real Linux commands. orezctl status and orezctl hardware are read-only.
  • Use KDE Connect if installed to pair your Android phone; pairing is optional and user-approved.

Transparency and security

OREZ v0.1 does not run a local AI model, install root background services, listen for remote commands, or bypass Linux authentication. The first-login wallpaper script runs as your normal user and is visible at /etc/xdg/autostart/orez-initialize.desktop. Remove or disable it in Autostart settings. Change wallpaper directly in KDE.

Source and status: OREZ-OS repository. The next milestone is a verified boot, installer and recovery path on the target MSI B550M / RTX 3050 machine.
